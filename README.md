# Neural Network from Scratch

This project implements a fully connected feedforward neural network from scratch, without relying on deep learning frameworks such as TensorFlow or PyTorch.

The implementation focuses on the core mechanics of neural networks, including forward propagation, backpropagation, and gradient-based optimization.

## Project Overview

The goal of this project is to understand the mathematical foundations of neural networks by implementing each component manually.

Topics covered include:

- Feedforward neural networks
- Forward propagation
- Backpropagation
- Gradient descent optimization
- Activation functions
- Loss functions
- Model evaluation
